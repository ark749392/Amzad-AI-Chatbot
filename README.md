# Amzad AI Chatbot

A Java-based rule-driven AI chatbot developed using Java Swing, basic NLP processing, and a JSON knowledge base.

## Features

- Java Swing graphical user interface
- Basic NLP text preprocessing
- Rule-based chatbot responses
- JSON-based knowledge base
- Multiple AI and programming topics
- Conversation memory
- Send button and Enter key support
- Clear chat option

## Technologies Used

- Java
- Java Swing
- Regular Expressions
- JSON
